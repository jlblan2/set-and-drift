# Set & Drift

A GPS-based set and drift calculator for marine navigation, installable to an iPhone home screen as a Progressive Web App.

Press **START** to log your position and time (Fix 1). After the vessel has drifted, press **STOP** to log the new position and time (Fix 2). The app computes:

- **Set** — the true-course direction from Fix 1 to Fix 2, shown in both **True** and **Magnetic**
- **Drift** — the speed of that movement, shown in both **knots** and **mph**

Magnetic variation is computed automatically from the Fix 1 location using the embedded WMM2025 world magnetic model (NOAA/NCEI coefficients, valid 2025.0-2030.0) — no setup required. A manual override is available under Settings for chart corrections or use after the model's validity window.

Runs must be at least a few seconds apart (configurable in Settings) for a reliable drift speed.

## Files

- `index.html`, `style.css`, `app.js` — the app
- `wmm.js` — offline World Magnetic Model (WMM2025) declination calculator
- `manifest.json`, `sw.js` — PWA manifest and offline service worker
- `icons/` — app icons (generated by `make_icons.py`, requires Pillow)

## Install on iPhone

1. Open this site's GitHub Pages URL in Safari.
2. Tap the Share icon, then **Add to Home Screen**.
3. Launch from the home screen icon — it opens full-screen, no browser chrome, and works offline after the first load.

Geolocation requires HTTPS, which GitHub Pages provides.
